# Logistic Regression From Scratch

A simple logistic regression model built from scratch using NumPy.

## What it does

The model takes humidity as input and predicts the probability of rain.

## Concepts implemented

- Sigmoid activation
- Forward pass
- Binary cross-entropy loss
- Gradient calculation
- Gradient descent
- Logistic regression
- Binary classification

## Dataset

This project uses a small manually created dataset for learning purposes.

- X = humidity (%)
- Y = rain (0 = No Rain, 1 = Rain)

pip install -r requirements.txt
